# Dados

Fichas de provedores, modelos, oportunidades e matrizes consolidadas.

## Subpastas

- `provedores/` — Fichas por provedor de IA
- `modelos/` — Fichas por modelo de IA
- `oportunidades/` — Oportunidades de acesso (programas, descontos, créditos)
- `matrizes/` — Visão consolidada (provedores vs. modelos)
